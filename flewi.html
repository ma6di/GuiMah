Peek at what’s coming

01 — Why

One pain. Then a platform.

German gender and plurals are where learners quit. Flewi started there — custom SRS, Artikel practice, auto-parsed cards — then grew into Spaces and multi-language learning without rebuilding the core.

02 — The gap

Anki depth. Native feel. Nothing in between.

Anki

Serious SRS. Brutal UX. Build every card by hand.

Duolingo

Great loops. Shallow depth. No real user decks.

Quizlet

Easy sharing. Generic cards. No grammar parsing.

03 — Stack

Self-hosted. Boring on purpose.

Web

React · Vite · Tailwind · PWA

Mobile

Expo / React Native — product source of truth

Backend

FastAPI · PostgreSQL · Redis

Infra

Docker · Caddy · Hetzner
